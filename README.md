# Predicción de tsunamis

Proyecto Integrador — Ciencia de Datos (UTN FRM, 5.º año, Ingeniería en Sistemas de Información).

## Pregunta de investigación

¿Qué características de un sismo permiten estimar si está asociado a un tsunami?

Preguntas que complementan la información de la pregunta principal:
* ¿Qué características de un sismo están relacionadas con la ocurrencia de un tsunami?
* ¿Cómo influye la magnitud de un sismo en la ocurrencia de un tsunami?
* ¿Cómo influye la profundidad de un sismo en la ocurrencia de un tsunami?
* ¿Qué características permiten diferenciar los sismos asociados a tsunamis de aquellos que no lo están?

## Fuente de datos

Se usa la [API de USGS https://www.usgs.gov/](https://earthquake.usgs.gov/fdsnws/event/1/#kmlanimated), una API pública de solo lectura que no requiere cuenta, API key ni autenticación.
